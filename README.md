## 📌 Sobre o Projeto

O **Rastreador de Despesas** é uma aplicação web interativa desenvolvida para gerenciar o orçamento pessoal e categorizar gastos de forma prática. Este projeto prático do Sprint 7 do bootcamp de Desenvolvimento Web da TripleTen teve como foco introduzir a lógica de programação com **JavaScript**, transformando uma interface estática em um sistema dinâmico de controle financeiro.

N esta etapa, o trabalho concentrou-se na implementação de cálculos básicos, manipulação de arrays e objetos, estruturação de funções matemáticas e atualização dinâmica das estatísticas e categorias de despesas.

---

## 🎯 Objetivos de Aprendizado

- Compreender a integração entre **HTML, CSS e JavaScript**.
- Manipular dados estruturados utilizando **arrays e loops**.
- Escrever **funções lógicas** para processamento de cálculos financeiros (totais, médias, saldo e categorias).
- Aplicar estruturas condicionais para alteração dinâmica de estados visuais (como alertas de orçamento).
- Organizar e modularizar scripts para funcionamento sequencial.

---

## 🛠️ Tecnologias e Conceitos Utilizados

- **HTML5 & CSS3**:
  - Interface visual e estilização pré-definidas para exibição de painéis, listas e formulários.

- **JavaScript (ES6+)**:
  - Declaração de variáveis (`let`, `const`) e estruturas de dados (arrays aninhados).
  - Laços de repetição (`for` / `forEach`) para percorrimento de coleções.
  - Funções matemáticas e condicionais para cálculo de orçamento, despesas totais, média e saldo.
  - Manipulação de escopo e fluxo de execução de scripts interdependentes.
